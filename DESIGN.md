# Werewolf Woods — Design Doc

Multiplayer asymmetric chase game (1 werewolf vs. many settlers), inspired by
Warcraft 3's **Tree Tag**. Built in **Godot 4.5**, GDScript, 2D with a faked
Don't Starve-style 3/4 camera. All art is drawn in code (no image assets yet).

## Core loop
1. **Scatter** — settlers spawn in the central clearing and run outward.
2. **Build** — settlers pick a spot in the forest or mountains and build a camp.
3. **Hunt** — the werewolf spawns and searches for them.
4. **End** — the match ends when the werewolf has caught every settler.

## Decided
- Art: pixel art generated in ChatGPT, snapped to real pixels with Pixel Snapper. Reference scale: settler 43 px tall; trees placed at 2.0–2.6x so pixels match: pine_tall 90x166, pine_dark 54x104, dead_pine 65x228, dead_tree 68x175; mushroom_brown 18x16; bush_small 49x35, bush_big 75x64, stump_log 79x45, fallen_tree 123x41 (resampled from larger art to the settler's pixel density); stump 38x29, log 58x25, boulder 38x30, mossy rock 24x20, ferns 42x29/33x25, grass tuft 18x17, mushroom 15x17, pebble 17x12, stick 19x13 (all at 1x); grass tile 131x129. Camera zoom 3x.
- Animation: H3 (ComfyUI, fl2va) for run cycles. Settler run cycles imported in 8 directions (right 29 frames, up 16, down 12, up_right 16, down_right 30; left side = mirrored right side). Diagonal idles = standing first frame of their video. Diagonals were sampled at ~7.4x so their size matches the older sprites (native grid in those videos was ~6.9x, which made him ~10% bigger). Pipeline: key out green, sample each video frame back onto the native pixel grid (~7.2–7.7x upscale), snap colours to the settler palette, pick the cleanest loop, align feet with the idle sprite.
- Map is generated every round from the menu settings (map size + seed) by the WorldBuilder node in main.tscn (its forest/prop settings still apply). World/Props in main.tscn is only the editor preview. Hand-painted props go in World/Placed, or drag a prop scene straight into World (e.g. the tent): both are kept on every rebuild, as are Campfire and Spawn where you moved them (only Ground and Props are regenerated) (editor button + every round), and the generator keeps trees (Painted Tree Clearance, default 60 px) and other props (Painted Clearance, 16 px) clear of them - keep-out radius = half the painted prop's art width x its max scale, flattened for the 3/4 view; Keep Painted Visible also keeps trees out of the column in front of (below) a painted prop up to the tree's height, so canopies don't hide it. Painted props are also shaded (darkness ABSORB) and pushable (plant bend) like generated ones.
- Werewolf is a **player** in the final game; we start with an **AI werewolf**.
- The werewolf **escalates over time**: more power, clues and power-ups, so
  every match eventually ends.
- Map is **procedural from a seed** (multiplayer only needs to sync the seed).
- Fog of war: cell-based light around the settler that fades to black; props cast soft
  shadows and dense forest dims it.
- Camera: fixed 3/4 view, objects upright and y-sorted; trees fade when the
  local player is behind them. No camera rotation (would require real 3D).

## Open questions
- Build phase length before the wolf spawns?
- What can settlers build (walls, campfire, traps…)? Costs / resources (wood?)
- Escalation: time-based, per catch, or both? Which power-ups first?
  Ideas: smell fresh footprints, hear chopping/building, break walls faster,
  howl that reveals nearest settler, faster movement, map-wide pings late game.
- Caught settlers: out, spectate, rescuable, or become wolves?
- Settler goal/score: survival time ranking, reaching dawn, or other?
- Campfire: there is now one in the central clearing (light + particles). Its light is visible from afar in the dark: light/warmth vs. revealing your position.

## Current state (prototype)
- World in main.tscn (built by WorldBuilder): grass Ground layer (80x80 tiles), Props layer with a seeded forest of two pine types (Tree Mix weights in WorldBuilder; the original pine.png was removed) + dead trees (~8%) + stumps, logs, boulders, mossy rocks, ferns, grass tufts, mushroom groups, pebbles and sticks around a central clearing, a Campfire at the centre (0,0), Spawn marker just south of it.
- Props are scenes (built from the PROPS table in tools/build_world.gd) with optional collision, vision blocker (pine trunks, boulders) and fade when the player is behind them. Big props (pine, stump, log, rocks) stay visible as silhouettes; small ground cover (ferns, grass, mushroom, pebble, stick) hides in line-of-sight shadow. All use scripts/varied_prop.gd for per-instance size/colour/flip. Paintable via the Props TileMapLayer (scene tiles, 8 px grid).
- Settler: AnimatedSprite2D built in code — idle stills + H3 run cycles in 8 directions (up/up_right/right/down_right/down, left side mirrored), WASD, Shift sprint (unlimited, no stamina). Every run cycle is given its own `cycle` time in player.gd `RUN` (0.5 s by default) at walk speed and plays faster when sprinting.
- Fog of war via the player's vision light, fading to completely black. Tunables in the Inspector on the Main node (Fog group): fog_color, fog_darkness, vision_radius, fog_start, fog_density, vision_brightness, vision_tint, vision_squash, shadow_softness (also live-editable while running). Invisible walls + camera limits follow the painted ground.
- Trees: one shared 2.0–2.6x scale (TREE_VARY in tools/build_world.gd) so all tree pixels are the same size; living pines ≈200–430 px, dead trees ≈350–590 px, each with its own size, hue/saturation/brightness and mirroring picked from its map position (scripts/varied_prop.gd, tunables on the root of each prop scene, e.g. pine.tscn). Colour shift is done in prop_fade.gdshader via varied_material.tres.
- Idle: the settler breathes (sprite stretched up from the feet on a sine wave) and drifts slightly while standing still (assets/characters/idle_breathe.gdshader); fades in after stopping, off instantly when moving. Settings in Main > Idle.
- Hitboxes: trunk/rock/stump collision and vision blockers are flat ellipses centred where the trunk meets the ground (measured from the art, 3-7 art px above the foot point; PROPS table "at"/"vision_at" in tools/build_world.gd), mirrored with the sprite. Light shading (darkness.gd BASE_AT) uses the same points.
- Tree trunks never touch: WorldBuilder rejects a tree if it is closer sideways than both root widths + Trunk Gap while its base lies within the front tree's visible trunk height (TREE_SHAPE in world_builder.gd, art px, at each tree's max scale). Dead trees are placed first since their whole trunk is visible.
- Bushes (small/big): walk-in hiding spots - not solid; they bend when pushed and cover a player standing in them. (Their one-sided vision blockers only matter if Crisp Shadows is turned on.) Fallen trees and stump+log are solid, low (no sight block). Collision/vision blockers mirror with the sprite.
- Start menu (scripts/start_menu.gd): over the paused, dimmed forest - title + Start/Settings/Quit, then Choose your side: Human / Werewolf / Back. Main > Show Start Menu; chosen side in main.player_role.
- Esc menu (scripts/escape_menu.gd): opens during a round WITHOUT pausing (multiplayer) - the night and the werewolf keep going and your character stands still (player.input_enabled off). Resume (or Esc again), Quit to main menu (leave the round), Quit game - in the same button style as the main menu. Resume has focus so Enter never quits by accident.
- Settings (main menu > Settings AND Esc menu > Settings - one shared panel, scripts/advanced_settings.gd; it used to be "Advanced settings", Esc menu only): tabs General (Fullscreen/Windowed, Difficulty, Volume, Music), Map (size, seed, forest density/mix/props + Regenerate map = restart the round with the new forest, same side), Weather (+ Rain now / Clear now), Day & Night (+ jump to Day/Dusk/Night), Fog & Vision, Werewolf & Wind. Built from the @export hints of Main / WorldBuilder properties listed in SECTIONS (add a name there to expose it). Applies live (map on regenerate), saved in user://settings.cfg [advanced], re-applied every round; Reset to defaults = main.tscn values (General kept). Game keeps running behind it. Opened from the main menu there is no Regenerate button: map changes rebuild the forest behind the menu when Settings is closed (scene restarts into the menu).
- Player settings (now in the General and Map tabs of Settings above): map size (Small 50 / Medium 80 / Large 120 tiles), map seed + Randomize, "new random seed every round", Fullscreen/Windowed (F11 also saves it), Difficulty (Easy/Normal/Hard/Nightmare = AI werewolf speed x0.85/1/1.12/1.25), master volume. Stored in scripts/game_settings.gd (static, survives round reloads) and saved to user://settings.cfg. Changing map size/seed restarts the scene so the new forest shows. Current seed + size shown in the HUD. Generation takes ~0.1 s (Medium) to ~0.25 s (Large). Trees fill the map right up to its edge: the tree grid runs past the map by the jitter and only trunks that land on the map are kept (TREE_EDGE in world_builder.gd = how close a trunk may stand to the sides/top/bottom), so edge density matches the inside.
- Werewolf (scripts/werewolf.gd, extends player.gd): idles right/up/down (left mirrored), runs right (12-frame gallop, mirrored left), up-right (13) and down-right (14) (left diagonals mirrored), up (12) and down (13) - all 8 directions. ~73 px tall = 1.7x the settler (43), art resampled from the user's stills + three H3 run videos (keyed green/magenta, snapped to a 40-colour werewolf palette). Walk 140 / sprint 215. Playable from the menu (swaps the settler out), or as an AI hunter when playing human: spawns at dusk (see Day & night) at least Spawn Distance away, wanders, chases within Sense, searches the last-seen spot when beyond Lose, catches on contact -> "You were caught!" and the round restarts. Non-local characters use character_material.tres (prop shader: night darkness, no fade). Settings in Main > Werewolf.
- See-through: standing behind a prop fades only a soft area hugging your body (player.see_through_size, follows the werewolf's pose); Main > See-through (scale, softness, alpha).
- Footprints (scripts/footprints.gd): the villager leaves faint alternating prints every stride (longer when sprinting), drawn above the ground and below props/darkness; each holds full strength then fades (lifetime, fade start). Settings in Main > Footprints. Not left by the werewolf.
- Footsteps (player.gd): one grass step sound (assets/sounds/footsteps/grass_step.wav) cut straight from the freesound running-in-grass clip (only a plain volume gain and 3/30 ms edge fades, imported uncompressed). Never pitched or randomised. Synced to the run animation: each RUN / W_RUN entry has "steps" = foot-down points in the cycle (0..1); settler right/down_right strips hold two strides so they have four. Sprint raises the animation speed_scale, so steps come faster. Your own steps play non-positional; other characters (the AI werewolf) play positional (AudioStreamPlayer2D) up to Werewolf Hear Distance, so you can hear it before you see it. Sound can be swapped any time: Main > Footsteps > Settler/Werewolf Step Sound (any AudioStream), or in code character.set_step_sound(stream) (null = default), e.g. per ground type later; takes effect from the next step. Settings in Main > Footsteps (sounds, volumes, hear distance).
- Day & night (scripts/day_night.gd): each round starts in daylight (Day Length, default 45 s), then dusk fades the light over Dusk Length (20 s) into night, which lasts the rest of the round. main.gd drives the look from the clock every frame: scene tint day_tint -> dusk_tint (sunset) -> the Fog night tint; the darkness overlay fades in via darkness.gd set_night() (only the darkness amount changes, no relighting, vision radius stays fixed); campfires glow dimly by day (campfire glow_scale). The AI werewolf spawns when dusk starts (or when night falls: Main > Werewolf > Werewolf Spawns At). N skips to the next phase (debug). Settings in Main > Day & Night (incl. Start Time for testing). Open: dawn as a settler win condition.
- Weather (scripts/weather.gd + scripts/rain.gd): rounds alternate clear and rain spells (Rain Chance, Clear/Rain Spell min-max seconds), scheduled from the map seed so every player gets the same weather; rain fades in/out over Rain Fade. Rain = GPUParticles2D streaks above everything, lit by the same light map as the ground (rain.gd shader reads the dk_* darkness values from the prop material), so at night they only show in your vision and around campfires + ground splashes under the darkness (only seen in your light at night) + looping rain sound (assets/sounds/weather/rain_loop.wav: a generated placeholder, swap via Rain Sound) + greyer tint (Rain Tint) + stronger wind in the trees + footprints wash away faster + the AI werewolf's steps carry less far. T toggles rain (debug). Settings in Main > Weather.
- Rabbits (scripts/rabbit.gd, assets/characters/rabbit.tscn): ~15 px tall, made from three H3 hop videos with tools/rabbit_from_video.py (green key, best loop per direction, shared palette, outline): idle + 11-12 frame hop strips facing right (left mirrored), up and down. Sit and look around, hop about, flee (zig-zag, faster hops) when the settler comes within 110 px or the werewolf within 170 px, until everyone is 280 px away; dark at night like other characters; nobody collides with them, they collide with trunks/rocks/walls; sleep beyond 1500 px from every character. Characters are in the "scares_rabbits" group (player.gd). WorldBuilder scatters them (Animals > Rabbits, per million px2, placed randomly and evenly anywhere on the map, only avoiding trunks/rocks/logs, painted props and the fire pit; in dense forest many sit hidden under canopies) into World/Rabbits, rebuilt each round and not saved; or drag rabbit.tscn into World. Behaviour settings on the rabbit.tscn root.
- Werewolf howl (assets/sounds/werewolf_howl.mp3, freesound/universfield "wolf howl"): plays once when the AI werewolf spawns, positioned at its spawn point (AudioStreamPlayer2D, max distance 8000, gentle panning) so you hear roughly which way it is; when you play the werewolf it plays at dusk. Main > Werewolf > Werewolf Howl / Howl Volume.
- Music (scripts/music.gd, assets/music/ambient_01-10.mp3, the user's tracks): shuffled day list (07, 01, 02, 08, 05) until dusk starts, then the night list (06, 09, 03, 04, 10) - split by measured brightness (darker, bassier = night), editable in Main > Music. Shuffle bag (whole list before repeats, never the same twice in a row), 4-14 s quiet gap between tracks, 4 s fade-in, 6 s fade-out at dusk. Per-track loudness correction (TRACK_GAIN_DB, to about -18 LUFS; files untouched). Lives under the tree root, so it carries on across round restarts and in the paused menu. Plays on a "Music" bus; Settings has a Music slider (game_settings.music_volume).
- Camera: smooth follow (smoothing 5) + physics interpolation (project setting) to remove stutter from 60 Hz physics vs. screen refresh.
- Display: starts fullscreen (project.godot window/size/mode=3), F11 toggles windowed. Camera: Main > Camera > Camera Zoom (default 1.0 = far), Scroll Zoom off by default. Vision radius 380 px to suit the far camera.
- Darkness (scripts/darkness.gd): light cells that react to the props. Each prop makes its ground cells soak up light (ABSORB table: trunks most, canopies/bushes some, rocks/logs a little; scaled by Trunk/Canopy/Prop Shade). Light travels outward from the settler (and campfires) in straight lines cell by cell (each cell takes the light from one step back towards the source, bilinear), so props cast soft shadow wedges and dense forest dims it. A cell shows the light reaching it (no dark boxes). Recalculated only when the player enters another cell (~2.3 ms); campfire once. Blended cells (Cell Softness 2-4) or crisp squares (1). The darkness overlay is drawn in the world between ground (z -10) and props (z 0), so it only darkens the ground; props are lit by PROXIMITY in prop_fade.gdshader: distance from the player to the closest point on the prop's trunk line, same fade curve as the ground (radius/start/density/squash); campfire light read at the base. Shadows are only on the ground, so nearby props are never dark. Directional shading: the side of a prop facing away from the player darkens (Prop Side Shade), and props dim when the player stands behind them (Prop Back Shade). Nothing moves by itself. Settings in Main > Fog.
- Chopping: left click swings the axe (scripts/player.gd, strips assets/characters/settler_chop_right.png and settler_chop_left.png built from H3 videos by tools/chop_from_video.py (right = ClipProj_H3_00018, left = ClipProj_H3_00005); facing up/down he chops toward his last sideways side; he stands still while swinging). At the impact frame player.chop_hit fires; scripts/tree_chopping.gd finds the tree trunk (collision Body) under the blade, shakes it and throws chips; after Tree Hits (living) / Dead Tree Hits it topples away from you (collision and vision blocker gone at once), then becomes a stump scene tile sized to the trunk, and the night darkness is rebuilt. Hold the button to keep chopping. Sounds assets/sounds/chop.wav and tree_fall.wav (thud when a tree lands) are synthesized placeholders (tools/make_sounds.py). Settings in Main > Chopping.
- Felling pine_tall splits it (SPLIT in scripts/tree_chopping.gd): at the moment it goes, the tree's own image is cut at row 144 into two full-size halves drawn exactly where the tree was (invisible swap, also with the project's pixel snapping); the top falls pivoting on the trunk at the cut, the bottom stays and shows a cut face ~0.3 s in (assets/props/pine_tall_stump.png, made by tools/make_pine_stump.py from pine_tall.png + the ring face of tools/art/stump_face_source.png). Afterwards the tile becomes pine_tall_stump.tscn, which has pine_tall's size/colour/flip settings and so rolls the identical look: the stump never moves. Other trees still use the generic stump.tscn.
- Experience (Main > Experience; scripts/experience.gd): tasks give XP via add_xp(amount, source); felling a tree gives XP by type (big pine / small pine / dead tree). XP for level n -> n+1 = First Level XP x n ^ XP Curve (1 = linear 10, 20, 30 ...; 0 = flat; 2 = steep). Each level-up pauses the game and shows up to three upgrade cards (scripts/level_up.gd; click or 1-3; several level-ups queue): Swift Axe (chop speed), Light Boots (walk + sprint speed), Heavy Blade (trees and stumps need Hits Saved Per Level fewer hits per level, never below 1; trees start at Tree Hits = 7). Each card rolls a rarity (Epic Chance 5%, Rare Chance 25%, else Common; green/blue/purple): a Rare card counts as Rare Power (2) normal levels of its upgrade, an Epic as Epic Power (3); every card counts once towards the max level. Upgrade table, rarities and max levels: scripts/upgrades.gd; strength per level in the Experience settings; effects in main.gd _apply_upgrades. Thin deep-purple XP bar (150 px) right under the health bar with "x / y XP" to its right, level next to the health bar (hud.gd). Icons: tools/make_ui_icons.py.
- Stump wobble: hits that land while the felled tree is still falling already count towards the stump; they now wobble the cut stump half (split pines: the "Stump" sprite) or, for other trees, the stump prop as soon as it appears (_pending_shake in tree_chopping.gd).
- Stumps (stump.png and pine_tall_stump.png, STUMPS in scripts/tree_chopping.gd) can be chopped out (hittable the moment the tree starts falling; hits are kept by position and carry over to the stump prop): as many hits as a tree (Stump Hits 0 = same as Tree Hits, minus Heavy Blade), then it sinks away and drops a log and 1-2 twigs, gives XP Stump (1) and the darkness is rebuilt.
- Building: B opens the build menu (scripts/build_menu.gd) listing scripts/buildables.gd (Campfire: 3 stones + 3 twigs; Torch: 1 log + 2 twigs - assets/props/torch.tscn, art torch.png 27x70 native pixels; Workbench: 5 stones + 5 logs - assets/props/workbench.tscn, 62x33 (scaled down from the 95x51 source art to match the settler), group "workbenches"; recipes with "needs": "workbench" only show in the menu within WORKBENCH_RANGE (90 px) of a built workbench; footprints can be round (radius) or rectangular (Vector2 size); red costs = not enough). Picking one starts the placer (scripts/placer.gd): a see-through preview follows the mouse with its footprint green (fits) or red (out of Build Reach, off the map, or something solid under it - the blockers' collision shapes are outlined in red). Left click builds (materials taken), right click / Esc / B cancels; the player doesn't chop while placing. Built fires light the night (darkness rebuilt). Fires and torches (scripts/campfire.gd, group "interactables") are lit when placed; walk up and press E to put them out / light them again (fire, light, sound and their hole in the night darkness). The campfire sound is positional (AudioStreamPlayer2D, fades out by 650 px).
- Top-left HUD (main.gd _update_clock): "Survived: m:ss" counts up from the moment you pick a side (stops when you die; keeps running with the Esc menu open, paused on level-up), and under it your map coordinates in ground tiles (X/Y, 0/0 = map centre by the campfire, Y grows southwards). The old controls hint line at the top is gone. God-mode banner sits under them.
- Menu buttons light up only under the mouse: keyboard focus draws nothing (StyleBoxEmpty focus in start_menu.gd _button/_theme), so Enter still works but nothing looks stuck-highlighted.
- Clicks on the HUD (health box, tools bar, backpack) and on the build menu are stopped by those panels (MOUSE_FILTER_STOP), so they never start an axe swing.
- Tools bar: 1 Axe (chops), 2 Spade (digs: animation + a puff of soil, no effect yet), 3 Pickaxe (mines ore nodes, see Mining), 4 Watering Can (pours: animation + water, no effect yet; never runs out for now).

Icon: tools/art/src_watering_can.png -> assets/ui/watering_can.png (upright, 40x28).
- Spade dig: assets/characters/settler_dig_right.png (18 frames 41x48, from ClipProj_H3_00025 via tools/chop_from_video.py side "dig_right"; dig = frame 9), player.gd DIG; facing left plays it mirrored. player.dig_hit -> main.gd _on_dig_hit (soil particles).
- Built fires and torches are shaded like props (campfire.gd gives their Sprite varied_material.tres with a neutral tint): dark at night unless their own fire or your light is on them. Before, they showed in pitch black. Icons for the tools, Twig and Log are the user's art (tools/art/src_*.png) turned into slot-sized icons by tools/make_item_icons.py: finds each image's pixel grid and samples it back to native pixels (saved as tools/art/native_*.png), tools are rotated 45 degrees RotSprite-style (Scale2x x3, rotate, shrink) with the head/blade to the top right, then everything is mode-downsampled to <= 40-44 px -> assets/ui/<name>.png. - Night eyes (scripts/night_eyes.gd, Main > Night Eyes; toggle/glow/close distance also in Settings > Day & Night): about 1 in 100 living pines (Eyes Tree Share, picked from the map seed so everyone sees the same trees; ~40 on Medium) get a pair of tiny glowing eyes in the canopy, 30% chance of a second pair and again of a third. They fade in from deep dusk to night, blink every 2-7 s (sometimes a double blink), follow the wind sway of their canopy, shut when you come within Eyes Close Distance (150 px) and vanish when the tree is felled. Drawn with their tree (y-sorted), so trees in front still hide them.
- Ore gleam: prop_fade.gdshader has an opt-in gleam (uniforms gleam / gleam_period / gleam_color; 0 = off for every other prop). assets/props/copper_material.tres = the prop shader with gleam 0.28: every few seconds a soft diagonal glint sweeps over the ore-coloured pixels (saturated orange, not the outline), and the brightest ore pixels twinkle faintly; per-node timing from its position; quantized to art pixels; added before the night darkness so it only shows where lit. main.gd copies every other uniform from varied_material to it each frame (_sync_ore_material). Dropped Copper Ore uses it too (items.gd "gleam": true).
- Drag and drop (hud.gd), backpack AND tools bar: hold left on an item and drag it onto another slot - the item lifts out (source dims), the slot under the mouse gets the orange border; release = move: within the backpack inventory.move() (swap, or top up the same item's stack); within the tools bar a swap; tools can go between the bar and the backpack (a tool in the backpack is a 1-stack); only tools ("tool": true in items.gd) can go into the tools bar, anything else snaps back. Release anywhere else = nothing changes. A plain click on a tools-bar slot selects that tool. Handled in hud.gd _input (before the GUI) using the mouse events' own positions, so clicks on slots never reach the world (no axe swing); off while the Esc menu is open (hud.blocked). Closing the backpack cancels a drag.
- Mouse cursor: the user's pixel-art arrow (tools/art/src_cursor.png -> assets/ui/cursor.png 15x23 native, cursor_2x.png 30x46; tools/make_item_icons.py). main.gd _apply_cursor sets it as the arrow cursor (hotspot = the tip) after the display mode is set and on window resize; it is also set in project.godot (display/mouse_cursor/custom_image) so it shows from the first frame; the 2x copy on screens 1440 px tall and up.
- Recoloured art: all prop, tile, UI and character PNGs were harmonised to one forest palette by the user's tools/recolor.py (ramp-aware remap; characters keep their colours and only get the shared outline). New art from tools/make_item_icons.py / chop_from_video.py has to go through recolor.py too (the cursor and the sneak strip did).
- Sounds (tools/make_sounds.py, all synthesized placeholders): the settler's footsteps are three soft grass-step takes (assets/sounds/footsteps/grass_soft_1-3.wav) played in turn (player.gd step_takes; the project never had the old grass_step.wav, so steps were silent before); the werewolf has its own heavier werewolf_step.wav (werewolf.gd). Every swinging tool has a whoosh (swing_axe / swing_pickaxe / swing_spade / swing_can.wav, player.gd SWING_SOUNDS) timed from its strip so it peaks just before the hit frame (SWING_LEAD 0.24 s); the can's swish comes with the lift. Volume player.swing_volume_db (-8).
- Regrowing: pouring the watering can on a stump (the splash point, within 18 px of its trunk) regrows the tree at once (tree_chopping.gd regrow_at): a felled tree comes back as exactly the tree that stood there (scene remembered per stump in _felled_from; size/colour/flip come from the map position), pine_tall_stump -> pine_tall, other map stumps -> pine_dark. The tree springs up (stretches from the ground with a little overshoot, puff of leaves) and the darkness is redrawn.
- Sneaking: hold Ctrl (action "sneak"). Speed = walk x sneak_speed_scale (0.45), no sprint, no footstep sounds (the sneak animation isn't a run_ animation), no footprints (footprints.gd), and the AI werewolf only notices you within sense_radius x sneak_sense (0.45) while it isn't already chasing (werewolf.gd). Art: assets/characters/settler_sneak_right.png (from ClipProj_H3_00031 via chop_from_video.py side "sneak_right": frame 0 crouched still, 1-4 step loop at 5.5 fps), side view only, mirrored for left, tilted forward by SNEAK_LEAN (0.14 rad) around the feet because the filmed crouch is too upright. Not in god mode.
- Item tooltips (hud.gd): hovering a backpack or tools-bar slot shows the item's name (items.gd "name") in a small box just above the pointer, straight away; hidden while dragging.
- Survival (Main > Survival): health (scripts/main.gd; werewolf bites take Werewolf Damage every Bite Interval with knockback, the werewolf backs off after each bite; slow regen after Regen Delay; at 0 "You were killed!" and the round restarts). HUD (scripts/hud.gd, CanvasLayer above the darkness): health bar bottom left, tools bar bottom centre (keys 1-4; axe in slot 1, left click chops only with the axe), backpack of Inventory Slots (Tab / I; scripts/inventory.gd, stacks per scripts/items.gd). Pick up (scripts/pickups.gd): walk within Pickup Reach, the nearest item gets an "E" prompt; pebbles -> Stone, sticks -> Twig (map props, indexed by cell), and dropped items. Dropped items disappear after Drop Lifetime (30 s); map stones/sticks never do. Felled trees drop logs and twigs along the fallen trunk (DROPS in scripts/tree_chopping.gd). Item table: scripts/items.gd. UI icons: tools/make_ui_icons.py -> assets/ui/.
- Wind: each prop sprite is sheared like a hinge at its base on a plain sine wave (vertex shader in prop_fade.gdshader); timing shifts slowly across the map so the forest moves as a wave. Settings in Main > Wind (strength, speed, lean, wave length, direction); per-prop "Sway" on each prop scene root (trees 1.0, dead trees 0.35, ferns 0.6, grass 0.8, rocks/logs/stumps 0).
- Plants: ferns, grass and mushrooms bend away when the settler walks through and spring back with a wobble (scripts/plant_push.gd, Sprite skew, only plants near the player). Settings in Main > Plants; per-plant "Bend" on each prop scene root. Only the local player pushes plants so far.
- Campfire: CPUParticles2D Fire/Core/Embers/Smoke + flickering PointLight2D that casts trunk shadows (scripts/campfire.gd: light_radius, light_energy, flicker_*).
- Debug: F = god mode (no fog, mouse-wheel zoom, walk through everything, 4x speed, free camera; F again restores). Settings in Main > God Mode. Old procedural map still available (Main > Use Generated Map), but it uses the old code-drawn art.

## Files
- `main.tscn` — Main > World (y-sorted): Ground (TileMapLayer, grass), Props (TileMapLayer, scene tiles), Spawn (Marker2D).
- `assets/characters/` — settler_up/down/right/up_right/down_right.png (idle), settler_run_<same>.png (horizontal run strips; frame sizes/offsets in player.gd `RUN`).
- `assets/props/` — prop PNGs + one .tscn per prop, props_tileset.tres, varied_material.tres + prop_fade.gdshader (shared fade + colour variance), campfire.png/.tscn.
- `assets/tiles/` — ground-pixel-snapper.png (105x107, the ground tile) + ground_tileset.tres. grass.png is the old 131x129 tile, no longer used.
- `tools/world_builder.gd` — WorldBuilder node in main.tscn: set map size (ground_tiles), seed, clearing, forest density and per-prop amounts (Props group) in the Inspector, click **Rebuild World**, save. Replaces the World node.
- `tools/build_world.gd` — rebuilds prop scenes, tilesets and the World (OVERWRITES painted World). Prop collision/vision sizes are in its PROPS table; World settings come from the WorldBuilder node.
- `tools/build_campfire.gd` — makes campfire.tscn once (OVERWRITES particle tweaks if re-run).
- `scripts/main.gd` — entry point: fog settings + darkness, player, world setup, borders, HUD, input.
- `scripts/player.gd` — settler movement, sprite direction, vision light, camera. Tunables: `WALK_SPEED`, `SPRINT_SPEED`, `RUN[...].cycle` (per-direction run speed).
- `scripts/map_generator.gd`, `scripts/prop.gd`, `scripts/map_preview.gd` — old procedural map (optional).
